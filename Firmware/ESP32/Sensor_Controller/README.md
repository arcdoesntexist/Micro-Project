# Combined USB controller firmware

ใช้ไฟล์ Sensor_Controller.ino กับ ESP32 บอร์ดเดียว เพื่อเลือก FSR/Load Cell จากเมนู Unity โดยไม่แฟลชสลับ ใช้ HX711 by Rob Tillaart 0.6.5 ที่ติดตั้งอยู่และ ESP32 core เดิม ไม่มี MQTT/Wi-Fi หรือไลบรารี JSON เพิ่ม

| Input | Pins | ช่วง/ตัวคูณ |
|---|---|---|
| FSR ซ้าย (เปลี่ยนตัวใน 2.1.0) | GPIO34 | ปล่อย 4095, กดอ้างอิง 156.5 |
| FSR ขวา | GPIO35 | ปล่อย 4095, กดอ้างอิง 156.5 |
| Load Cell ซ้าย 1 kg | DT32, SCK18 | -2449.84 counts/g |
| Load Cell ขวา 5 kg | DT33, SCK4 | -429.11 counts/g |

เลือกบอร์ดและพอร์ตจริงใน Arduino IDE แล้ว Verify/Upload เอง จากนั้นปิด Serial Monitor ก่อนให้ Unity/Browser เปิดพอร์ตเดียวกัน ใช้ 115200 baud และรับ JSON หนึ่งบรรทัดต่อ frame; สเก็ตช์ bench เดิมทั้งสองชุดยังเก็บไว้

FSR เริ่มทำงานทันทีเป็นระดับสัมพัทธ์ 0–100% ไม่ใช่ N ส่วน Load Cell เริ่มต้นเป็น uncalibrated เสมอ เอาน้ำหนัก/แรงกดออกจากทั้งสองตัวแล้วกด Tare ใน Unity หรือส่ง t จาก Serial Monitor เพื่อวัดศูนย์ใหม่ ไม่ควร tare ขณะบีบ/วางของ ห้ามกดเกินพิกัด โดยเฉพาะตัว 1 kg

Tare เก็บ 5 samples ต่อช่องและต้องได้ sample ถัดไปภายใน 1000 ms จากนั้นรออีก 3 samples สำหรับค่าเฉลี่ยแรง หากช่องหนึ่งไม่พร้อม อีกช่องและ FSR ยังอ่านต่อได้ ค่า N ยังเป็น Estimated Force ตาม calibration ชั่วคราว จุด 83 g ยังไม่สอดคล้องกับจุด 228/525 g จึงต้องทดสอบจริงหลังประกอบ

ส่ง telemetry ประมาณ 20 ครั้ง/วินาที แต่ค่า Load Cell อัปเดตตาม data rate ของ HX711 ไม่ใช่ 60 Hz ใช้ sequence/bootId/tareId และอายุ sample เพื่อให้ Unity ทิ้งข้อมูลเก่า ช่องที่ไม่พร้อมส่ง N/age เป็น null ไม่แสร้งเป็น 0 N ค่าแรงติดลบคงไว้ใน diagnostic; เกมแยกจัดการค่าบีบและสถิติ

FSR ทั้งสองข้างปล่อยอยู่ที่ ADC เพดาน 4095 จึงไม่สามารถยืนยันว่ากดเบาอ่านได้ละเอียด หรือแยกการปล่อยกับสายหลุดบางลักษณะได้ ไลบรารี HX711 ยังมี race เล็กน้อยหากสายหลุดพอดีระหว่าง is_ready กับ read แต่การรอหลาย samples/tare ไม่ block วงรอบนี้

ไม่มีการอัปโหลดบอร์ดหรือเปิดพอร์ตจริงจากการสร้างไฟล์นี้

Micro-Project Version 0.1.0 สืบทอด combined firmware จาก CPS Version 2.1.0 และเก็บค่าของ FSR ซ้ายตัวใหม่ตามสเก็ตช์ที่ผู้ใช้แก้และยืนยันว่าเล่นได้แล้ว ค่า 551/135 ใน `../FSR_Reading` เป็นค่าของชุด bench เดิม ไม่ใช่ค่าที่ใช้ใน combined firmware ปัจจุบัน โปรโตคอลยังเป็น version 1 และ calibrationVersion ของการแปลง Load Cell ยังคงเดิม เพราะไม่ได้เปลี่ยนตัวคูณ HX711
